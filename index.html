一、运输方式管理（按优先级排序）

每种运输方式有独立的"国内→FBA 时效"与"最小批次量"。算法会按"最便宜且能在到货周前到达"原则自动选方式：先按优先级从前往后匹配，命中"国内到 FBA 时效 ≤ 当周"的第一个即可；命中方式后再按其最小批次量向上取整。↑ / ↓ 可调整优先级。「是否启用」开关：停用的方式不参与备货计算、也不出现在批次下拉里（无需删除，随时可重新开启）；已排好的历史批次不受影响，重新生成方案后生效。🚚 发货模式=中转的产品，总前置期 = 国内到FBA时效 + 海外仓到FBA时效（海外仓需留出备货发货时间），并额外要求海外仓保有「海外仓保底天数 × 月均预测」的库存。
优先级 运输方式 单位运费(¥/KG) 海外仓到FBA时效(天) 国内到FBA时效(天) 最小批次量 是否启用 操作

一(补)、FBA 上架天数设定

FBA上架天数指货物到达FBA仓库后，完成接收、贴标、上架等处理并可售所需的时间（天）。此参数用于计算「预计到仓时间」= 需求出货日期 + 运输方式时效 + FBA上架天数。

算法说明（备货需求计算逻辑）

以下为「生成备货方案」的需求计算逻辑说明，供核对口径使用。核心链路：月度预测 → 周需求 → 到货基线 → 库存模拟 → 缺口识别 → 备货量计算 → 批次下单。
① 输入（产品级字段）
类别字段
需求月预测 M0~M5（6 个月）、预测起始月份、最新周销量 / 近四周销量（无月预测时兜底）
库存FBA库存、下架库存、海外仓库存、挪用库存
在途/在制海外仓在途（+周数）、国内在途（+周数）、在制未交（+周数）、多票导入
参数安全库存周数、生产周期(天)、计划周期(天)、备货下单频率(天)、直发比例(%)、海外仓保底天数
② 周需求展开　月度预测 → 每周需求 = 月预测 ÷ 4.33（按月内周数均摊）
情况逻辑
有预测起始月份起始月之前的周 → 需求 = 0；起始月起的周 → 按「周所在月 − 起始月」偏移取对应 fcMx，超出 6 个月用平均值
无预测起始月份从第 0 周按 所在月索引（w÷4.33）取 fcMx 展开
无月预测（全空）兜底用 实际周销量 / 近四周销量 / 最新周销量
⚠️ 前导 0 月份不得 slice 掉（会左移错位）——直接按偏移取原始值，0 预测月的周需求自然为 0。
③ 到货基线
第 0 周 = FBA库存 + 下架库存 + 海外仓库存 + 挪用库存（期初可售）；之后各周 = 海外仓在途到仓 + 国内在途到仓 + 在制未交到仓（按各自到仓周数）+ 多票在途/在制累加。
④ 库存模拟（逐周滚动）
指标公式 / 规则
期末可售期初可售 + 当周到货 − 当周需求
安全线（周级）周需求 × 安全库存周数
缺货判定可用量 < 周需求 → 缺货 = 周需求 − 可用量（期末 = 0）
预警判定期末可售 < 安全线 → 黄色预警（周次计划表显示）
⑤ 缺口扫描（按 cadence 逐轮评估，2026-09-03 v4）
每轮先做全量库存模拟（含已排补货），再从本轮 cadence 最快可补救范围（reachFrom = 最快方式到货周）起扫描：
firstStockout = reachFrom 起首个真断货周（available < 周需求，期末 = 0）。早于 reachFrom 的断货 无论本批还是更晚批次都无法挽回（不可避免历史断货），不再触发下单，避免因历史断货周永远存在而无限应急。
cadence 下单周 = 批序 × 频率周数（7天→0,1,2…每周一单；15天→0,2,4…；30天→0,4,8…每月一单）； 下单周 ≥ 计划期 或 常规到货周 ≥ 计划期且无断货需救 → 排单结束（不再升舱堆货）。
分档（用户三规则）：
① 常规滚动：常规方式到货周在计划期内、且不晚于首个断货周（无断货时只看能否到货）→ 用常规 35 天慢衔接，不因低安全线就升舱快运。
② 缺货能衔接（升舱）：常规到不了 / 到货晚于断货 → 升舱到最早能 ≤ 首断货周到货的方式。
③ 断货应急：连最快都救不回断货周 → fastestSub（最快方式）首批止损，后续批次接力。
⑥ 下单量（qty）
档位规则
应急档（到货周 ≥ 首断货周）qty = 到货周安全线（规则 2：不加当周需求——断货周需求已丢失，补不回已丢销量；最大即安全线，此后批次接力慢慢衔接）
衔接档（到货早于任何断货）反推 qty = 安全线 − (期初可售 − 周需求)，使「到货 + 期初 − 周需求 = 安全线」，到货后期末刚好回到安全线，不多补（规则 1/3）
到货周已 ≥ 安全线查 reachFrom..到货周 之间是否仍有真断货：无 → 本 cadence 空跑推进（高库存不产生垃圾单）；有 → 补足该断货周安全线
取整/上限按单箱向上取整；safetyCeiling = max(maxBatchSize, 安全库存×2 按箱取整) 防爆
⑦ 批次生成与下单
候选方式池：仅「基础数据 → 运输方式管理」中已启用的方式参与选方式与批次下拉（停用 = 临时移出候选池，无需删除；已排历史批次保留，重新生成方案后生效）。
下单周 cadenceOrderWeek = 批序(batchCount) × 频率周数(orderFreqWeeks)。
到货周 = floor((下单周×7 + 生产天数 + 运输天数 + 上架天数) ÷ 7)；到货周 ≥ 计划期(weeks) 的批次不生成。
常规慢衔接（用户规则 1/3 主路径）：库存充足期不空下；一旦某 cadence 到货周将低于安全线，即下单反推量， 常规海运逐周滚动到货衔接 —— 不会出现「一次性大额应急单 + 高价快运」（2026-09-03 修复前：W9 出 4,960 快船22）。
断货应急（规则 2）：首批 fastestSub、qty 封顶安全线，后续批次每轮重新评估，断货解除后自动转回常规滚动。
按发货模式拆子批：直发（早到）/ 中转（dom + osToFba 晚到）/ 混合（直发比例拆分两批，浅克隆 method 对象避免跨产品共享）。
循环终止：无缺口 / 下单周 ≥ 计划期 / 常规到不了计划期且无断货需救 / 达最大迭代数。
核心公式速记
指标公式
周需求月预测 ÷ 4.33
期初可售FBA + 下架 + 海外仓 + 挪用（第 0 周）
期末可售期初 + 到货 − 需求
缺货max(0, 需求 − 可用)
安全线周需求 × 安全库存周数
备货量按下单频率 = maxBatchSize（不再叠加窗口需求 + 安全线 − 可用量，也不叠加缺货补偿/保底）

列口径

月均需求以导入时按月预测计算为准：monthlyAvgImport(p)（fcM0~M5 中 >0 的均值、取整）；与 备货清单 / 分析结果明细「月均需求」逐品同源；预测全空 = 0，不使用销量兜底（2026-09-03 用户确认）
